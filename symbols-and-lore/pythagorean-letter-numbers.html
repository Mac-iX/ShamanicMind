Numerology · A–Z letter map

The pattern inside a name.

A guide to the repeating letter values commonly called Pythagorean numerology—and a reminder that a symbolic map is a lens, not a verdict.

Symbols & LoreNumerologyReading practice

One letter follows another; the count returns to one. In this system, a name becomes a pattern that can be read, questioned, and held lightly.

How the letter map works

The Pythagorean letter map gives each letter in the Latin alphabet a number from 1 to 9. It begins at A = 1 and moves in order; after I = 9, the sequence starts again at J = 1. This creates nine repeating correspondences across A–Z.

From letters to a number

Take the name “SOUL” as a simple example: S = 1, O = 6, U = 3, and L = 3. Added together, they make 13; reducing 1 + 3 gives 4. Some numerology traditions keep selected double-digit totals, and interpretations vary. This example only shows how this particular letter map works.

The map is a tool of symbolic interpretation, not a scientific measurement of identity or destiny. A name can prompt a question, but it cannot tell someone who they must be. Use the pattern as a starting point for reflection, with curiosity and discernment.

A note on the name

“Pythagorean” is the common modern name for this letter-to-number convention in numerology. An academic discussion describes the table as a way of assigning letters of a given alphabet to the digits 1–9, and notes that the result depends on the alphabet being used. The English A–Z map shown here is one convention among several; other systems assign letters differently.
