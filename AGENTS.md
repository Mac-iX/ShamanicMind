# Repo guidance for agents

For all ShamanicMind website, design, content, or visual updates, use **`.agents/skills/shamanicmind-site/SKILL.md`** and read the authoritative brand kit and site spec first.

Preserve earlier user-owned artwork; do not create a replacement logo. Keep all new changes in a reviewable branch or PR. Deliver clean accessible, maintainable artifacts rather than exploratory leftovers.
