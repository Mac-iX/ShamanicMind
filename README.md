# ShamanicMind

Symbolic readings, self-knowledge, and a growing editorial library devoted to the meaning of symbols. The visual system follows the original artwork: midnight navy, warm gold, and a restrained purple logo accent.

## Website
- `index.html` — responsive, lore-led landing page with personal story and full A–Z Pythagorean numerology map.
- `symbols-and-lore/index.html` — the Symbols & Lore journal, with completed articles only.
- `symbols-and-lore/pythagorean-letter-numbers.html` — researched guide to the repeating letter map.
- `symbols-and-lore/prana-chakras-tattvas.html` — illustrated founding essay.
- `styles.css`, `app.js` — reusable accessible frontend styles and interaction.
- `assets/tattvas/`, `assets/illustrations/` — original scalable SVG art (decorative; not a new brand logo).
- `brand/BRAND_KIT.md` — visual system, copy voice, and design constraints.
- `content/reading-offers.json` — authoritative service pricing and unresolved checkout fields.
- `content/site-story.md` — approved source for the first-person story section.
- `content/lore/` — editorial source in portable Markdown.
- `.agents/skills/shamanicmind-site/SKILL.md` — repo-local agent instructions. Read before editing.
- `docs/SITE_SPEC.md` — implementation and handoff brief.

## Preview
Run `python3 -m http.server 8080` in the repository root and open `http://localhost:8080/`. This is dependency-free HTML/CSS/JS, suitable for review while the previous Work build or a future Next.js application is evaluated.
