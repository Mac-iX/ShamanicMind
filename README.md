# ShamanicMind

Symbolic readings, self-knowledge, and an editorial library devoted to the meaning of symbols.

## First website foundation
- `index.html` — responsive landing-page prototype.
- `symbols-and-lore/index.html` — Symbols & Lore library.
- `symbols-and-lore/prana-chakras-tattvas.html` — illustrated founding essay.
- `styles.css`, `app.js` — reusable accessible frontend styles and interaction.
- `assets/tattvas/`, `assets/illustrations/` — original scalable SVG art (decorative; not a new brand logo).
- `brand/BRAND_KIT.md` — visual system, copy voice, design constraints.
- `content/reading-offers.json` — authoritative service pricing, with pending terms explicitly null.
- `content/lore/` — editorial source in portable Markdown.
- `.agents/skills/shamanicmind-site/SKILL.md` — repo-local agent skill. Read before editing.
- `docs/SITE_SPEC.md` — implementation and handoff brief.
